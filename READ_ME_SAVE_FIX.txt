SCLASS CLOUD SYNC V3

Do this:
1. In Supabase, go to SQL Editor.
2. Run SUPABASE_RUN_THIS_SQL_FIRST.sql again.
3. Deploy this ZIP to Vercel.
4. Open the app.
5. Click Test Cloud.
6. If test passes, click Save To Cloud.
7. Open app on another device and click Load From Cloud.

- on_conflict upsert
